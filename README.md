## 🚀 Featured Project

### 📈 [Stock Predictive Model](https://github.com/gowrishs1718-source/Stock_Predictive_Model__Gowrishs-17)

A Python-based educational project that combines historical stock-market data, data processing, a saved deep-learning model, and a Flask web interface to visualise stock-price information and model predictions.

**Technologies:** Python · Flask · Pandas · NumPy · yfinance · scikit-learn · Deep Learning

- Retrieves historical stock data for a selected ticker.
- Displays summary statistics and moving-average charts.
- Uses a saved model to generate a prediction visualisation.
- Includes a sample dataset and a Jupyter Notebook.

**Note:** This is a learning project, not a financial product. Prediction quality should be validated with a documented test methodology before reporting accuracy.
